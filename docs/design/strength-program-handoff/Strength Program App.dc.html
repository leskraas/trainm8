1 Strength programs on mobile — trainm8

Built on the repo's dark tokens (--primary #35b89c, Public Sans, 24px card radius) and on ADR 0060: one scroll, three controls per row, a rest bar that never blocks logging, and a Stall Cut that offers nothing. Numbers come from program.constants.ts and rest.ts. The whole flow is clickable: tap a set circle to log it, tap again to count the reps down.
