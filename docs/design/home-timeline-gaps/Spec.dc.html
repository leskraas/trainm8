Home timeline — the handoff that was never committed

Every day is a row. Only some of them are sessions.

The rules

1The stream stays a record. The plan surface still owns seasons; the grid is a shortcut into authoring, not a replacement for planning.
2From today forward, every day is its own row. Behind today, runs of empty days collapse into one band that expands on tap.
3Rest day is written only where the Plan Outline prescribes recovery. Every other empty day is a blank cell with no label — the app does not name a day it knows nothing about.
4Tapping an empty cell turns it into a text field in place. ADR 0027 already decided a workout is authored as a typed sentence, so the cell editor and the authoring model are one thing.
5Past days take the same gesture. Typing there authors a Workout Session, not a recording — the actual still arrives by import, so the no-recorder non-goal holds.
6Empty rows sit at the 44px control floor; session rows keep the height their content earns. The grid reads from the 46px date gutter every row aligns to, not from uniform height.
7The discipline chip is prefilled from the athlete’s most-trained discipline and shown before commit. Derived, visible, one tap to change.

Rule 2 dissolves the rest-day bug rather than patching it: if every day forward renders, todayRowId is never null, so the landing, the collapse threshold and the back-to-today pill work on a rest day for free.
