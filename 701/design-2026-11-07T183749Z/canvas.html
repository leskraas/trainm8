Craft (emil-design-eng)

  • Two green buttons in Tilgjengelig (intervals.icu and Polar). This is the hub's existing pattern, not new here; flagged for the design scan, not changed in this build.
  • A refusal adds an alert above the well: two boxes for one visit. Acceptable because the code is gone on the next navigation.
  • No new motion: connecting is a page round trip through Polar, and sync is rare. Buttons keep pressable; dialog and toast keep their tokens.
  • The clock should not wrap away from "kl.": a no-break space in the rendered time.

Worst case (break-ui, report only): see the Worst case board. Device name is unbounded (FIT and AccessLink strings), so overflow-wrap:anywhere. A first sync that finds nothing: no device line, toast "Ingen nye økter å importere." dualSourceActive must count Polar.

Fit: the webhook ticket swaps one sentence in the well; the Model Sharing Opt-In ticket adds a switch row between well and actions. The anatomy has room for both.

Designer's pick (sealed before scoring): I mønsteret. Same as the critic's. The designer and the critic ran in one agent in this run (no subagent tool), so the critique is not independent; the pick was written to a file before the scoring.

Method: Emil's prototype skill (prototype-ui) is not installed, so its standalone branch was built by hand: one HTML file in the tokens of app/styles/tailwind.css, copy as labels.ts would hold it, shot with Playwright at 390, 1440, 320 and 195 wide (200% zoom).

Rejected directions: refusals as toasts, like Strava's callback (gone in 4 s, and "taken" is too long); the limits behind a "Hva deler Polar?" collapse (the criterion asks for honesty, and a collapse hides it); a "Kommer" card when unconfigured (that promises what is an operator setting).
