## Qualities checked that pass

- **Security, data isolation between athletes:** the session page reads the session through `getSessionByIdForUser(userId, …)` (`sessions.$sessionId.tsx:255`) before it passes the session's own `workout.id` to `readPlacedProvenance`. The reader selects only the slot's columns and never selects `takedownReason`. It drops the publisher's name unless `isPublished(row)` holds (taken down or orphaned reads "en utøver"). The other athlete's `description`, `ownerId` and `visibility` are read only to classify and are never returned. Tests pin the takedown reason's absence and the erased-author case.
- **Security, escaping and links:** `locatorHref` turns only `doi:` (to a fixed `https://doi.org/` host) and `http(s)://` into an `href`, so no `javascript:` URL is possible. Locators come only from the `corpus` branch (system rows; a community row cannot reach that branch). Links use `target="_blank" rel="noreferrer noopener"`. All text renders through React with no `dangerouslySetInnerHTML`.
- **Security, secrets:** nothing secret reaches the client or a log. The loader adds only `{ provenance, takenDown }`, and the Catalogue loader now sends the reading and `adaptedFrom` Citation, both already public.
- **Speed, Plan Preview:** the panel renders from `GeneratedSession.provenance`, which is already on the payload. A tap makes zero requests. Rows add no loader work.
- **Speed, N+1:** none. The session page makes one reader call per request, and the Catalogue's per-row work is unchanged.
- **Failure:** no new outbound call, so no timeout is owed. A missing, deleted, unsourced or non-Catalogue source renders nothing, with no placeholder, and an unsourced one is logged. The reader sits in the loader's `Promise.all`, so a database error there fails the page like its siblings do. That is the existing pattern and acceptable under `poc`.
- **Access, keyboard and screen reader:** the row is one native `<button>` (Base UI Trigger) with `aria-expanded`. Its accessible name is the day line plus the title, with the `·` separators `aria-hidden`. Enter and Space open the panel, and Escape closes it and returns focus. Route tests cover all of this. Focus shows the global `outline-ring/50`, since there is no `outline-none` on the row. The unfilled row is not a control (#429), and a test pins it.
- **Access, contrast:** I computed `muted-foreground` on the panel well (`bg-muted/60` over `card`) in light mode at 5.02:1; it is 4.72:1 on a fully `muted` hover fill. Both are at or above 4.5:1 for `text-footnote`. Dark mode is lighter text on a darker well and has more margin.
- **Access, target size:** the row is `min-h-11` (44 px). The locator link gets a 44 px hit area through `after:-inset-y-3.5`. Next to the link on the session page are only non-interactive badges, so the extended hit area steals no taps.
- **Mobile:** tap highlight is off globally (`tailwind.css:785`), `touch-action`/`user-select` apply to buttons globally, the press tint is instant (`active:duration-0`), and hover uses Tailwind v4's gated `hover:` and never opens a panel. A day-line token keeps `sone 4` together with an NBSP while `overflow-wrap:anywhere` breaks over-long words. Two new e2e cases in `tests/e2e/mobile-overflow.test.ts` cover 390 px with a panel open, and the session page with the longest Citation and a URL locator.
- **Motion (`review-animations`):** the chevron rotates with `duration-press` and ease-out, inside `motion-safe`. The panel keeps `motion-collapse` and its own reduced-motion answer, as ADR 0077 §5 and ADR 0085 §4 require. The panel above snaps shut (`transition-none!`) so the tapped row does not slide away. The reveal scroll is `block: 'nearest'` and instant under reduced motion. One Block-free caveat is finding 2.
- **Design system / luma steps (ADR 0085, main's ADR 0119):** only on-ladder classes are used (`rounded-2xl`/`3xl`, `text-footnote`/`callout`), so main's new `trainm8/luma-steps` rule should not fire after the rebase.
- **Data:** no schema change, migration, seed or new dependency in the diff.
- **Tests:** `readPlacedProvenance` is covered for generated, adopted (a real `updateWorkoutSession` fork), Catalogue placement, community, taken-down, unpublished/orphaned, retired, own fork, deleted source, own session and unsourced-with-log. The slot component has tests for wording, the corpus and community branches staying apart, adoption, and takedown. The preview route has tests for no line until tapped, one open panel, Escape (focus inside or elsewhere) and Enter. The session page has tests for notice de-duplication and slot order. The hold-in-place and reveal-scroll behaviour have no test; they need a real browser or phone (see finding 2).
- **Row key / ids:** `sessionRowKey` is unique, because the starter pattern places one endurance session per day per track (`starter-pattern.ts:133`). Panel ids and open state cannot collide.
