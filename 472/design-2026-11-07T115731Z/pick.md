# Designer's pick (sealed) · #472 · run 1

**Pick: Two figures, one line.**

Reason: the athlete reads the generated week in the same words, with the same `≠` rule, as _Sesong_ shows it a minute after approval (`mål 32 km · planlagt 24 km, +1 uten km`). One row per track, with the names in a shared column, lets the figures line up down the card. It adds no picture of nothing done (no meter) and no third, blended number. Build it as a word-and-figure line on the shared `TrackWeekVolume`/`wordTrackWeek` reading rather than a second formatter, with the `·` hung at the end of the target group so a wrapped line starts with a label.

Only one variant was drawn (unattended run), so this pick is also the only candidate. The open question for the critic is whether the meter-less row is right, or whether _Sesong_'s `TrackMeter` should be reused as is (rejected in the appendix).
